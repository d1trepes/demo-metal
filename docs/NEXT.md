# Следующие чаты

## 10 — Оптимизация десктопа (решение пользователя 01.11.2026)
Жалоба: страницы грузятся долго, некоторые «зависают» на 2–3 с; видео и картинки должны появляться сразу, без задержек при прокрутке.
1. Замерить, а не гадать: Lighthouse (десктоп) и Performance-трейс в Chrome на главной, `/catalog/`, `/product/…`, `/about/`, `/contacts/`, `/account/` — по деплою на Pages, не локально. Записать цифры «до».
2. Найти, что блокирует поток на 2–3 с (кандидаты: карта отгрузок с d3-geo и контурами регионов, 70 плиток каталога с появлением, typograf, Яндекс.Карта, гидратация больших JSON — `products.json` в клиентских бандлах).
3. Чинить по найденному: разбить бандлы (`dynamic` для тяжёлого), не тащить весь `products.json` в клиент, `content-visibility`/ленивые блоки, предзагрузка видео и постеров, `loading="lazy"` + `decoding="async"` + заранее заданные размеры у всех картинок, prefetch ссылок шапки, шрифты.
4. Видео hero и склада: постер сразу, видео стартует без пауз; проверить вес и кэш.
5. Замерить «после», записать в PROGRESS. Цель: Lighthouse десктоп ≥ 95 на всех страницах, без длинных задач > 200 мс.

## 11 — Мобильная версия + общая проверка
360 px всех страниц, Lighthouse моб. (главная ≥ 85, остальные ≥ 90), битые ссылки, тексты → `docs/HANDOFF.md`.
