## Открытые проблемы
- 11в, проверить на iPhone: (1) Telegram — hero и блоки не «дышат» (`--vh-fixed`); (2) Safari — тёмное под подвалом, белое сверху; не красит ли тёмный fixed-слой нижнюю панель Safari 26 посреди страницы — если да, слой показывать только у подвала; (3) /contacts — видна ли ч/б заглушка `static-maps.yandex.ru/1.x` (без ключа; в песочнице сети нет, если не грузится — нужен скрин карты в `public/`), тормозит ли grayscale на iframe.
- 11б, проверить только на iPhone: свайп вбок (/login, /kp), белое под подвалом, дёрганье в Telegram — в Chrome-эмуляции не воспроизводятся. Видео hero на 3g: Safari не отдаёт тип сети, там решает только canPlayVideo.
- Вкладки кабинета: `touch-action: pan-x` не ставили — мешал бы вертикально листать страницу, если палец лёг на полосу; хватило `overflow-y: hidden`.
- Яндекс.Карта на /contacts в песочнице не грузится (нет сети) — проверить на GitHub Pages: метка, ч/б, вес iframe для Lighthouse.
- В песочнице `next build` падает на Turbopack (нет нативных бинарников) — собирать `npx next build --webpack`; в CI обычный `npm run build`.
- Карта: перетаскивание пальцем проверено только эмуляцией; 60 к/с измерено в headless Chrome на 1440.
- Кабинет: в песочнице шрифты на скриншотах грузились запасные — проверить на Pages.
- Lighthouse десктоп на Pages не мерили (из песочницы Pages недоступен; замеры чата 10 — локально, CPU ×4). Пользователь проверил на Pages: лагов нет. Lighthouse — в чате 11.
- Lighthouse для /about, /contacts не мерили (рендер площадки — LCP, 800 px копия на телефоне).
- Картинки: все пришли в 1200 px (бриф просил от 2000) — для сайта хватает, крупнее 1200 не показываем. `pages/base` — кривая надпись на вывеске, мелкие люди, жёлтый кран; `pages/pack` — ленты обесцвечены (`scripts/cutout-7b.py`). Картинки /constructions вырезаны «обратным multiply» — рассчитаны только на белый фон.
- Контуры регионов РФ — набор 2013 г. (83 субъекта).
