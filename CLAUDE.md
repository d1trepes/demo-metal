# Демо «Пролёт» — правила для каждого чата

Демо-сайт металлобазы и цеха металлоконструкций для холодных продаж веб-студии. Один чат = один пункт плана из `docs/PASSPORT.md` §11.

## В начале каждого чата
1. Прочитай `docs/PROGRESS.md` (что сделано, что дальше) и `docs/DESIGN.md` (стиль, сетка, запреты).
2. Открой скриншоты референсов в `docs/refs/`, относящиеся к блокам этого чата. Это главный ориентир по виду: делаем на их уровне, но в нашем монохроме.
3. Читай только файлы кода, нужные для пункта. Весь репозиторий не читай.

## Картинки — сначала бриф, потом блок (обязательно)
Перед вёрсткой любого блока, которому нужны картинки (фура-разделитель, рендеры конструкций для панелей, фото цеха, иллюстрации страниц и т. п.):
1. Сначала сверься с референсами в `docs/refs/` и `DESIGN.md` → «Изображения», реши, какие картинки нужны.
2. Напиши пользователю список: файл, где стоит, размер/формат, готовый промпт по шаблону из `docs/BRIEF-assets.md` (один стиль на все). Допиши этот список в `docs/BRIEF-assets.md`.
3. **Остановись и жди картинки.** Пользователь генерирует их сам. Не верстай блок с заглушками и не генерируй картинки сам.
4. Когда картинки пришли — проверь, что пришли все и нет дублей (сравни файлы), вырежи фон, сохрани исходники в `docs/assets-src/`, готовые WebP в `public/`, и только потом верстай блок.

## Неизменные правила
- Источник правды по продукту — `docs/PASSPORT.md`, по виду — `docs/DESIGN.md`, значения — `styles/tokens.css`. Решили иначе — обнови документ и скажи пользователю.
- Цвета, шрифты, отступы, радиусы — **только токены**. Никаких случайных значений.
- **Одна сетка** (DESIGN.md → «Сетка»): все блоки через общие `Container`/`Grid`, края совпадают с шапкой. Полноширинным бывает только фон.
- Монохром: белый, чёрный, стальные серые. Цвет — только статусы и видео hero.
- Запрещены ИИ-шаблоны: надзаголовки над заголовками, точки-маркеры, эмодзи, иконки над карточками, одинаковые карточки «иконка + заголовок + текст», градиенты, неон, большие скругления, тени везде, лишние анимации.
- Тексты как у настоящей металлобазы: ГОСТ, марки стали, размеры, тонны, сроки, ₽/т.
- Все обращения к «серверу» — только через `lib/api.ts` (заглушки), каждая функция описана в `docs/HANDOFF.md`. localStorage — только в try/catch.
- Мобильная версия проверяется на 360 px: нет горизонтального скролла, таблицы прокручиваются внутри себя.

## В конце каждого чата
`npm run build` → коммит с понятным сообщением → обновить `docs/PROGRESS.md` (сделано / осталось / проблемы) → коротко пользователю: что готово, где посмотреть, что в следующем чате.

Общение — по-русски, коротко, сначала результат.
